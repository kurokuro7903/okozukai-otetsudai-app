# お小遣い・お手伝いアプリ（公開版）

お手伝いをゲームの「クエスト」に変える、小学生〜中学生向けのお小遣いアプリです。
クエストをクリアすると経験値（EXP）とお小遣いが貯まって、レベルが上がるごとに相棒キャラクターが5段階に進化します。

## 特長

- 相棒キャラはドラゴン／ネコ／ロボットの3種類から選択、全5段階に進化
- 親画面は4桁PINでロック。子どもの登録（複数可）・クエスト編集・承認・支払い記録は親だけが操作できます
- 外部通信・広告・課金なしで、家庭内で安全に使えます

## 使い方

`index.html` をブラウザで開くだけで使えます（GitHub Pagesでもそのまま表示できます）。

1. 親画面でPINを設定し、子どもとお手伝いクエストを登録する
2. 子どもがクエストを終えたら「できた！」を押す
3. 親が承認すると、EXPとお小遣いが貯まる

## 注意

この公開版は、ブラウザで開いている間だけデータを保持する「お試し・紹介用」です。ページを閉じたり再読み込みすると入力内容はリセットされます。
